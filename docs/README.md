# tjedu 문서 안내

사람이 읽거나 작업하는 것은 이 `docs/` 아래에 둔다.
웹 주소로 열리는 것은 `public/` 으로, 둘 다 아닌 것은 `legacy/` 로 보낸다.

## 하위 6자리

`docs/` 아래 폴더는 이 여섯뿐이다. 여기에 없는 이름은 만들지 않는다.

| 자리 | 담는 것 |
|---|---|
| `research/` | 시장·경쟁·자료 조사 기록 |
| `brand/` | 브랜드 정의 — 브레인스토밍·페르소나·포지셔닝·브랜드 브리프 |
| `handoffs/` | 세션 인계 기록. 다음 사람이 이어받을 내용. 다른 곳에서 넘어온 글은 `from-(보낸 곳)-YYYY-MM-DD.md`, 이 프로젝트가 남기는 마감 기록에는 `from-` 을 붙이지 않는다 |
| `decisions/` | 결정 기록. 무엇을 왜 그렇게 정했는지 |
| `decks/` | 발표용 덱(pptx·키노트·덱 성격 pdf) |
| `design/` | 웹에 안 나가는 디자인 원본 — psd·ai·sketch·raw·고해상도 시안 |

비어 있는 자리도 지우지 않는다. `.gitkeep` 을 넣어 남겨 둔다.
